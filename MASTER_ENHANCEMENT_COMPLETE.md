   - Notch support for iPhone X+
   - Bottom bar spacing

## 🎨 **DESIGN SYSTEM**

### Colors:
```
Primary: Emerald (#10b981) → Cyan (#0891b2)
Secondary: Purple (#8b5cf6) → Pink (#ec4899)
Accent: Amber (#f59e0b) → Orange (#f97316)
Therapy: Warm, calming pastels
```

### Typography:
```
Font Family: Inter (sans-serif)
Sizes: 12px, 14px, 16px, 18px, 20px, 24px, 30px, 36px, 48px
Weights: 400 (normal), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold)
```

### Spacing:
```
xs: 4px, sm: 8px, md: 16px, lg: 24px, xl: 32px, 2xl: 48px, 3xl: 64px
```

### Border Radius:
```
sm: 4px, md: 8px, lg: 12px, xl: 16px, 2xl: 24px, 3xl: 32px, full: 9999px
```

### Shadows:
```
sm: subtle, md: normal, lg: elevated, xl: prominent, 2xl: dramatic
```
